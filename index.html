    See the example assumptions

    This demo uses fixed, invented values for illustration. They are not market prices or executable quotes.

    • WETH: $2,400 · DAI: $1 · USDT: $1 · WBTC: $64,000.
    • USDC is assumed to equal $1 in this illustration.
    • Example output = selected value × 99.85%, rounded to cents. The 0.15% adjustment is an arbitrary demo assumption, not a provider fee.
    • Demo inputs allow up to 8 decimal places. A selection that rounds to zero output cannot be reviewed. These are demo display limits, not live trade limits.
    • Example network cost = $2.50 for a swap + $0.65 per required example approval, paid separately in ETH.
    • Only WETH has a sufficient example allowance. Actual allowances, token support, quotes and costs must be checked live.

    A focused starting point

    Small tool.
    Clear purpose.

    Gatherport is an independent wallet utility in development. We are building a simpler way to choose which tokens to keep, gather selected balances into USDC and understand the outcome before taking action.

    Our first focus is Ethereum, with clear asset selection, transparent cost breakdowns and control that stays with the wallet owner. The interactive demo is available today; live pricing and wallet execution are planned.

    A few useful details

    Before you try it.

    Where the prototype stands, and what comes next.

    Can I swap real tokens here?

    Not yet. This is an interactive prototype with synthetic data. It does not connect a wallet, request quotes, ask for approvals or execute transactions.

    Which wallets and tokens will be supported?

    We are starting with Ethereum. The first live version is planned around compatible wallets and eligible tokens with a usable route into USDC. The demo assets are illustrative; the supported list will be established through testing.

    Will I need to approve each token?

    A live flow may need a separate approval for each sell token that does not already have sufficient allowance. Gatherport plans to show these requirements before execution. The current demo only illustrates that review.

    Why start with USDC?

    One destination makes the review easier to understand. The first planned workflow focuses on consolidating selected Ethereum balances into USDC in the same wallet. More destinations can be considered after the core flow is validated.

    Does this demo collect wallet information?

    No. This demo uses hard-coded example data in your browser. It has no wallet connection, account registration, analytics, cookies or application-level network requests. A hosting provider may process routine access logs when the page is published.
