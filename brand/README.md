# Gatherport brand assets

**Tagline:** Bring your tokens together.

The original mark combines three incoming lines into one destination.

- `gatherport-mark.svg`: coral mark on a transparent background.
- `gatherport-avatar.svg`: scalable avatar.
- `gatherport-avatar-512.png`: 512 × 512 avatar for GitHub, X, and Telegram.

## Palette

| Role | Color |
| --- | --- |
| Paper | `#F7F5EF` |
| Ink | `#2B302B` |
| Coral | `#CC5737` |
| Sage | `#E7EBDF` |

The website uses system sans-serif fonts and Georgia, so it does not load remote fonts. Keep the mark centered when applying a circular profile crop. Name, account, domain, and trademark availability are not established by these assets.
